# Attack-Lab
## Attack Simulation & Defense Lab

### Project Overview
A practical cybersecurity lab designed to simulate
attacks, analyse network traffic, monitor authentication
logs and detect suspicious activities.

### Lab Environment
- Kali Linux – Attacker machine
- Ubuntu Linux – Target and monitoring machine
- VirtualBox – Virtualization platform
- OWASP Juice Shop – Vulnerable web application

### Tools Used
- Nmap
- Wireshark
- Python 3
- OpenSSH
- Docker

### Completed Activities
1. Virtual lab environment configuration
2. Network connectivity testing
3. Nmap reconnaissance
4. Wireshark traffic analysis
5. SSH failed-login simulation
6. Python-based SSH detection

### Detection Results
The Python detection script identifies suspicious
SSH login activity by analysing failed authentication
attempts and counting attempts by source IP.
